# Bayan Park Hub

Individual final project for HUMCOM1 (Human Computer Interaction), University of Baguio.
A website for East Bayan Park, Aurora Hill, Baguio, addressing waste and park upkeep.
SDG 11: Sustainable Cities and Communities.

- Tech: HTML5, CSS3, basic JavaScript (no Bootstrap)
